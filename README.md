## Projects

###  [Õppekaardid – Flashcards App](https://github.com/jurjenson/proge_projekt)
A desktop app for creating and studying flashcards, with a simple **spaced repetition** system. Built together with Minna Marie Kask.
- Create, edit and delete card sets and cards
- Study mode with *Know / Don't know* buttons, shuffling, a session timer and a progress bar – cards you don't know come back at the end
- Per-card statistics saved in **SQLite** (times seen, correct/wrong answers, last result)
- Import and export sets as **JSON** and **CSV**
- Generates an **HTML report** with a summary and per-card statistics

`Python` `CustomTkinter` `SQLite` `JSON / CSV` `HTML / CSS`

###  [Structura/Tartu vald – Volleyball Club Website](https://github.com/Artus-lm/Veebileht)
A (semi-)official website that gathers all information about the volleyball club Structura/Tartu vald, which plays in the Estonian First League. Made in a team of three for the *Introduction to the Speciality* course.
- Four pages: home page with past and upcoming games, club and player introductions, a registration form, and a *"Which position suits you?"* quiz
- Design based on the colours of the team's kit
- **My role:** lead designer

`HTML` `CSS` `JavaScript` `JSON` `Python (web scraping)`

###  [Web Application Development](https://github.com/jurjenson/WAD_HW)
Team homework for the *Web Application Development* course – a social-media-style front end with a post feed, a login page, an "add post" page and a profile drop-down menu. Posts are loaded from a JSON file with JavaScript.

`HTML` `CSS` `JavaScript` `JSON`
