# Hello, I'm Annabel

I study Computer Science at the University of Tartu (2nd year). Most of what's here started as course projects: a flashcard app, a couple of websites and some web dev homework. Right now I'm also working on a POS system with my Software Engineering team.

## Projects

### [Õppekaardid (Flashcards App)](https://github.com/jurjenson/proge_projekt)
A desktop flashcard app I made with Minna Marie Kask. You can make your own card sets and study them. If you mark a card as "don't know", it comes back at the end of the round. The app saves stats for every card in SQLite, can import and export sets as JSON or CSV, and can generate an HTML report of your progress.

Python, CustomTkinter, SQLite

### [Volleyball club website](https://github.com/Artus-lm/Veebileht)
A website for Structura/Tartu vald, a volleyball club in the Estonian First League, made in a team of three for the Introduction to the Speciality course. It has the club's past and upcoming games, player introductions, a registration form and a quiz that tells you which position suits you. I did most of the design, based on the team's kit colours.

HTML, CSS, JavaScript, Python (web scraping)

### [Web Application Development homework](https://github.com/jurjenson/WAD_HW)
Team homework for the Web Application Development course: a small social media style site with a post feed, login page, "add post" page and profile menu. The posts are loaded from JSON.

HTML, CSS, JavaScript
